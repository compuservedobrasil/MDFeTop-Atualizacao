# MDFeTop — pacote de atualizacao

Repositorio **publico exclusivo** para distribuir o pacote compilado do MDFeTop (`AtMDFeTop.zip`).

## O que ha aqui

- **Somente binarios** publicados em [Releases](../../releases) (sem codigo-fonte).
- Mesmo modelo do FTP Compuserve: `AtMDFeTop.zip`, `AtMDFeTop_<versao>.zip`, `manifest.json`, `PathNotes.txt`, `NotasVersao.txt`, `versao.txt`.

## URLs estaveis (ultima versao)

Substitua `compuservedobrasil` pelo usuario/org deste repositorio:

- Manifesto: `https://github.com/compuservedobrasil/MDFeTop-Atualizacao/releases/latest/download/manifest.json`
- Pacote fixo: `https://github.com/compuservedobrasil/MDFeTop-Atualizacao/releases/latest/download/AtMDFeTop.zip`
- Notas: `https://github.com/compuservedobrasil/MDFeTop-Atualizacao/releases/latest/download/NotasVersao.txt`

## Privacidade

Este repositorio **nao** contem fontes `.pas`, `.dfm`, `.dpr` nem projetos Delphi.
O historico git da pasta raiz fica minimo (README / .gitignore). Os ZIPs ficam apenas nos Releases (CDN do GitHub).

## Publicacao

Feita pela Compuserve via `PublicarAtualizacaoMDFeTop.ps1` (FTP + Google Drive + este GitHub).
